## 📌 Project Objectives

- Define a clear and detailed test plan.
- Design manual test cases to cover functional and UI requirements.
- Execute test cases and record results manually.
- Ensure quality assurance through thorough documentation.

---

## 📝 Test Plan

Located in the `/TestPlan` directory, the test plan includes:

- Scope & Objectives
- Testing Approach
- Entry & Exit Criteria
- Resource Requirements
- Schedule & Milestones
- Risk Management
- Deliverables

---

## ✅ Test Cases

Each test case includes the following fields:

- **Test Case ID**
- **Test Scenario**
- **Test Steps**
- **Expected Result**
- **Actual Result**
- **Test Status (Pass/Fail)**
- **Comments/Remarks**

Test case types:

- Functional Test Cases (`Functional_Test_Cases.xlsx`)
- UI Test Cases (`UI_Test_Cases.xlsx`)
- Integration Test Cases (`Integration_Test_Cases.xlsx`)

---

## 📊 Test Execution Reports

Test run results and status are documented in the `TestExecutionReports` folder. This includes:

- Execution Date
- Tester Name
- Test Environment
- Summary of Pass/Fail Count
